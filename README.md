# BookMatch · TFM

Trabajo Fin de Máster del **Máster de Especialización en Inteligencia Artificial y Big Data** (DigitechFP).

Web para descubrir libros con un sistema de recomendación por Machine Learning. Usa datos reales de [goodbooks-10k](https://github.com/zygmuntz/goodbooks-10k) y un pipeline de datos en capas Bronze, Silver y Gold.

## Estructura

```
bookmatch-tfm/
├── notebooks/   Notebooks de exploración, pipeline de datos y modelos
├── docs/        Web estática publicada en GitHub Pages
└── data/        Datos del pipeline (fuera del repositorio)
```

## Datos

Los datos no se suben al repositorio. Para reproducir el proyecto:

1. Descargar goodbooks-10k desde https://github.com/zygmuntz/goodbooks-10k
2. Guardar los CSV originales en `data/bronze/`
3. Ejecutar los notebooks en orden
